Using Gigasector

Build a rehearsal setlist with track-specific section markers.

  1. Upload an audio track, then open it in Player.
  2. Set A/B for the intro and C/D for the outro at the playhead.
  3. Use the Setlist arrows to arrange tracks in performance order.
